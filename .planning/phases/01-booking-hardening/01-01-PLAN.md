  <behavior>
    - Server fetches slip.price_per_night from DB; client-submitted totalPrice is ignored
    - Price = price_per_night * calculateNights(checkIn, checkOut)
    - Fee split: 10% yacht owner surcharge on top, 5% marina deduction from payout (15% total per user decision)
    - Stripe line items: two items — base price and "EasyDock service fee" (Airbnb-style)
    - Booking created via supabase.rpc('create_booking_atomic') — NOT sequential select+insert
    - On date conflict from RPC: return 409 with message "This slip is no longer available for those dates"
    - Validation: checkOut must be after checkIn (return 400 if not)
    - Stripe session has expires_at set to 30 minutes from now (Unix timestamp)
    - platform_fee_amount stored = 15% of base price (total fee, not just yacht side)
  </behavior>
  <action>
Rewrite `src/app/api/checkout/route.ts` completely. The new route:

1. **Auth check** — same as current (get user, return 401 if not authenticated).

2. **Parse request body** — accept `slipId, marinaId, checkIn, checkOut, vesselName, vesselLength, vesselType, specialRequests`. Do NOT accept or use `totalPrice` from the body. Validate that `slipId`, `marinaId`, `checkIn`, `checkOut` are present (400 if missing). Validate `checkOut > checkIn` (400 if not, message: "Check-out must be after check-in").

3. **Fetch slip with marina** — same query pattern as current: `supabase.from("slips").select("*, marinas!inner(*)").eq("id", slipId).eq("is_available", true).single()`. Return 400 if not found.

4. **Compute price server-side:**
   ```typescript
   import { calculateNights } from "@/lib/utils/format";

   const nights = calculateNights(checkIn, checkOut);
   const basePrice = slip.price_per_night * nights;
   const serviceFeeRate = 0.15;
   const yachtOwnerFeeRate = 0.10;  // yacht owner pays 10% surcharge
   const yachtOwnerFee = Math.round(basePrice * yachtOwnerFeeRate * 100) / 100;
   const totalChargedToCustomer = basePrice + yachtOwnerFee;
   const platformFeeAmount = Math.round(basePrice * serviceFeeRate * 100) / 100;
   ```

5. **Create booking via RPC** — use admin client (`createAdminClient()`) to call the RPC function:
   ```typescript
   import { createAdminClient } from "@/lib/supabase/admin";

   const adminClient = createAdminClient();
   const { data, error } = await adminClient.rpc('create_booking_atomic', {
     p_slip_id: slipId,
     p_marina_id: marinaId,
     p_boat_owner_id: user.id,
     p_check_in: checkIn,
     p_check_out: checkOut,
     p_total_price: totalChargedToCustomer,
     p_vessel_name: vesselName || '',
     p_vessel_length: vesselLength || 0,
     p_vessel_type: vesselType || '',
     p_special_requests: specialRequests || '',
     p_platform_fee_amount: platformFeeAmount,
   });
   ```
   - On error: return 500
   - On `data[0].conflict === true`: return 409 with `{ error: "This slip is no longer available for those dates" }`

6. **Create Stripe Checkout Session** with two line items (Airbnb-style):
   - Line item 1: `${slip.name} at ${slip.marinas.name}` — `unit_amount: Math.round(basePrice * 100)`
   - Line item 2: `EasyDock service fee` — `unit_amount: Math.round(yachtOwnerFee * 100)`
   - Set `expires_at: Math.floor(Date.now() / 1000) + 30 * 60` (30 minutes, Unix timestamp — NOT `expires_after`)
   - Include `metadata: { booking_id: data[0].booking_id }`
   - Same success/cancel URLs as current

7. **Return** `{ url: session.url, bookingId: data[0].booking_id }`

Use the user-authenticated supabase client for the slip lookup (respects RLS), but the admin client for the RPC call (the RPC function uses SECURITY DEFINER).
