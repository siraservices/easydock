    - POST with {address: "123 Main St, Miami, FL"} returns {lat: number, lng: number} when Mapbox returns a result
    - POST with {address: "..."} returns {lat: null, lng: null} when Mapbox returns no features

       - Disabled: `opacity-50 cursor-not-allowed`

       - POST handler accepting {address: string}
       - Read `MAPBOX_ACCESS_TOKEN` from `process.env`
       - Return 400 if address is missing or token is missing
       - Call Mapbox Geocoding v6: `https://api.mapbox.com/search/geocode/v6/forward?q=${encodeURIComponent(address)}&access_token=${token}&limit=1`
       - On success: extract `feature.geometry.coordinates` as `[lng, lat]` (v6 format -- NOT v5 `.center`)
       - Return `{lat, lng}` on success, `{lat: null, lng: null}` on no results or Mapbox error
