  <files>src/components/availability-calendar.tsx, src/__tests__/availability-calendar.test.ts</files>
  <behavior>
    - A day within a booking's check_in..check_out range (check_in <= day < check_out) is marked as booked
    - A day outside all booking ranges is marked as open
    - Cancelled and declined bookings are excluded from the booked calculation
    - An empty bookings array results in all days showing as open
    - Month navigation changes the displayed month
  </behavior>
  <action>
    1. Create `src/components/availability-calendar.tsx` ("use client"):
       - Props: `slips: {id: string, name: string}[]`, `marinaId: string`
       - State: `selectedSlipId` (default to first slip), `currentMonth` (Date, default to current month), `bookings` (fetched from Supabase)
       - Slip selector: `<select>` dropdown above the calendar, populated with slip names. On change, update selectedSlipId and re-fetch bookings.
       - Month navigation: Left/right arrow buttons flanking the month/year label (e.g., "March 2026"). Clicking changes currentMonth by +/- 1 month and triggers re-fetch.
       - Data fetch: On mount and when selectedSlipId or currentMonth changes, query Supabase:
         ```
         supabase.from("bookings").select("check_in, check_out, status")
           .eq("slip_id", selectedSlipId)
           .neq("status", "cancelled")
           .neq("status", "declined")
           .gte("check_out", startOfMonth)
           .lte("check_in", endOfMonth)
         ```
       - Calendar grid: 7-column grid (Sun-Sat header row). Fill leading empty cells for days before the 1st. Each day cell is a small square.
       - Day coloring logic (extract to a pure function `isDayBooked(day: Date, bookings: {check_in: string, check_out: string}[]): boolean`):
         - Return true if any booking has `check_in <= day` AND `check_out > day` (same-day turnover allowed per Phase 1 decision: strict < and > operators)
       - Booked days: `bg-red-100 text-red-700` (or `bg-gray-200 text-gray-500`)
       - Open days: `bg-green-50 text-green-700`
       - Days outside current month: `text-gray-300` (muted)
       - Legend below calendar: small colored squares with "Open" and "Booked" labels
       - If no slips exist, show empty state using `EmptyState` component or simple "No slips added yet" message
       - NO booking details shown per user decision -- only color coding

    2. Write `src/__tests__/availability-calendar.test.ts`:
       - Test the pure `isDayBooked` function (extract it as a named export for testability)
       - Test: day on check_in date -> booked
       - Test: day on check_out date -> NOT booked (same-day turnover)
       - Test: day between check_in and check_out -> booked
       - Test: day before check_in -> not booked
       - Test: day after check_out -> not booked
       - Test: empty bookings array -> not booked
       - Test: multiple bookings, day overlaps one -> booked
  </action>
