    2. Add NEXT_PUBLIC_MAPBOX_TOKEN to .env.local: Read the existing MAPBOX_ACCESS_TOKEN value from .env.local, then add a line `NEXT_PUBLIC_MAPBOX_TOKEN=<same pk.* value>`. Keep the original MAPBOX_ACCESS_TOKEN for the geocoding API route.

    3. Create `src/lib/hooks/use-map-filter.ts` with two pure exported functions:
       - `filterMarinasByViewport(marinas: Marina[], bounds: LngLatBounds): Marina[]` — filters marinas by bounds.contains([lng, lat]), excludes null lat/lng
       - `buildSlipQuery(supabase, filters: SearchFilters)` — builds the Supabase query: `.from("slips").select("*, marinas!inner(*)").eq("is_available", true).eq("marinas.is_active", true)`, adds `.not("marinas.lat", "is", null).not("marinas.lng", "is", null)`, adds `.gte("length_ft", ...)` if boatLength set, adds `.gte("width_ft", ...)` if boatBeam set. Does NOT filter by city. Returns the query object.

    4. Create `src/components/map-view.tsx` ("use client"):
       - Import Map, Marker, MapRef from 'react-map-gl/mapbox' and 'mapbox-gl/dist/mapbox-gl.css'
       - Props: `{ marinas: Marina[], onVisibleMarinaIdsChange: (ids: Set<string>) => void, hoveredMarinaId: string | null, onHoverMarina: (id: string | null) => void, onSelectMarina: (id: string) => void }`
       - Use mapRef to call getBounds() in onMoveEnd callback, filter using filterMarinasByViewport, call onVisibleMarinaIdsChange with visible IDs
       - Render Marker for each marina with valid lat/lng. Pin style: teal-600 circle with white anchor icon. Highlighted pin (hoveredMarinaId match): scale up + navy-800 color.
       - Marker onClick calls onSelectMarina
       - Marker onMouseEnter/onMouseLeave calls onHoverMarina
       - initialViewState: { longitude: -80.1, latitude: 26.1, zoom: 10 }
       - mapboxAccessToken from process.env.NEXT_PUBLIC_MAPBOX_TOKEN
       - mapStyle: "mapbox://styles/mapbox/streets-v12"
       - Initialize visibleMarinaIds to ALL marinas on first render (so list is not empty before first map move)

    5. Write tests in `src/__tests__/use-map-filter.test.ts`:
       - Test filterMarinasByViewport with mock bounds object that has a contains() method
       - Test buildSlipQuery with various filter combinations
       - Follow existing vitest pattern (node environment, no jsdom)
