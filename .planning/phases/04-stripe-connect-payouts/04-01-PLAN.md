<task type="auto">
  <name>Task 2: Connect onboarding API routes (onboard, return, refresh)</name>
  <files>src/app/api/connect/onboard/route.ts, src/app/api/connect/return/route.ts, src/app/api/connect/refresh/route.ts</files>
  <action>
1. Create `src/app/api/connect/onboard/route.ts` — POST handler:
   - Authenticate user via createClient().auth.getUser() — return 401 if not authenticated
   - Accept { marinaId } from request body
   - Verify user owns this marina: query marinas where id=marinaId AND owner_id=user.id
   - If marina already has stripe_account_id, check if onboarding is complete. If complete, return error "Already connected". If incomplete, skip account creation, just generate new account link for existing account.
   - Create Express account: stripe.accounts.create({ type: 'express', country: 'US', email: user.email, capabilities: { card_payments: { requested: true }, transfers: { requested: true } } })
   - Store stripe_account_id on marina BEFORE generating link (link is one-time-use): adminClient.from('marinas').update({ stripe_account_id: account.id }).eq('id', marinaId).eq('owner_id', user.id)
   - Generate account link: stripe.accountLinks.create({ account: account.id, type: 'account_onboarding', return_url: `${process.env.NEXT_PUBLIC_APP_URL}/api/connect/return?marinaId=${marinaId}`, refresh_url: `${process.env.NEXT_PUBLIC_APP_URL}/api/connect/refresh?accountId=${account.id}&marinaId=${marinaId}` })
   - Return { url: link.url }

2. Create `src/app/api/connect/return/route.ts` — GET handler:
   - Extract marinaId from searchParams
   - Fetch marina's stripe_account_id from DB using adminClient
   - ALWAYS retrieve account from Stripe to check actual status: stripe.accounts.retrieve(stripe_account_id)
   - Update marina: stripe_onboarding_complete = account.details_submitted, payouts_enabled = account.payouts_enabled
   - Redirect to dashboard with query param: /dashboard?stripeStatus=connected (if payouts_enabled) or /dashboard?stripeStatus=pending

3. Create `src/app/api/connect/refresh/route.ts` — GET handler:
   - Extract accountId and marinaId from searchParams
   - Generate fresh account link: stripe.accountLinks.create({ account: accountId, type: 'account_onboarding', return_url and refresh_url same as onboard route })
   - Redirect to link.url (not JSON response — this is a Stripe redirect target)

All routes follow existing patterns: getStripe() factory, createAdminClient() for DB writes, NextResponse.json() or NextResponse.redirect() for responses, try-catch error handling with console.error.

Environment variable needed: NEXT_PUBLIC_APP_URL for constructing return/refresh URLs.
